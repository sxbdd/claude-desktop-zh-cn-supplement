# Claude Desktop 中文化补丁

把 Claude Desktop 的界面**完整**变成简体中文。

分两步：先装上游汉化包（第三方项目，**已随本包附带，不用自己下载**），
再装本补充包补齐它漏掉的词条。

---

## 为什么需要「补充包」

上游项目 [javaht/claude-desktop-zh-cn](https://github.com/javaht/claude-desktop-zh-cn)（v1.4.7，
完整副本就在本包的 `upstream\` 里）的**中文词表收得不全**，这是它自身的目录问题，
不是安装失败：

| 词表 | 英文词条 | 上游自带中文 | 结果 |
|---|---|---|---|
| 菜单栏 / 对话框 | 705 | 362 | 其余 343 条显示英文 |
| 网页前端界面 | 29,442 | 12,037 | 其余 17,405 条显示英文 |

Claude 查不到中文就回落到英文原文。所以装完上游补丁后，界面会变成
「设置」是中文、「Keyboard Shortcuts」「Update now」还是英文的**半汉化**状态。

本补充包把缺的条目全部补齐：**29,442 个英文键全部有中文，缺键 0 条**。
只有品牌名、产品名、技术标识符（`Google Play`、`GitHub App`、`Claude Pro`、
`Anthropic Sans`、OAuth scope 串之类）按惯例保留原文。

---

## 前置条件

- Windows 10 / 11，已安装 Claude Desktop
- 已安装 Python 3（安装时勾选 **Add python.exe to PATH**）
  没有的话去 [python.org](https://www.python.org/downloads/) 下一个即可

## 安装

**上游汉化包已经打包在本目录的 `upstream\` 里。全程不需要联网，不需要自己去下载任何东西。**

把整个文件夹解压到**本地硬盘**（不要放在网络盘或压缩包里直接双击跑）。

**第 1 步**：双击 `第1步-安装上游汉化.bat`

按提示走，UAC 弹窗点「是」。上游安装程序会在新窗口里让你**选模式**：

> **请选「模式 1」。** 完整模式会修改 `app.asar`，会破坏 Cowork 和沙箱功能。

**等上游那个窗口全部跑完**，看到成功提示。

**第 2 步**：双击 `第2步-安装补充汉化.bat`

它会自动请求管理员权限，然后合并补充词表，最后打印覆盖率：

```
本次写入 2500 条。复核覆盖率：
    菜单栏 / 对话框：中文 784 条 / 英文 705 条，缺键 0 条
    网页前端界面：中文 31549 条 / 英文 29442 条，缺键 0 条
```

看到「缺键 0 条」就成功了。

**第 3 步**：完全退出 Claude Desktop 再打开

从**托盘图标右键退出**，光关窗口不够。重开后界面就是完整中文了。

## 版本与兼容性

**本包按 Claude Desktop 2.2553.1.0（Windows 商店版）制作。**
你的版本不一样也能用，只是覆盖程度不同——原因见下。

**怎么查自己的版本**：打开 Claude Desktop → 设置 → 关于；
或者看它的安装目录名，形如 `Claude_2.2553.1.0_x64__pzs8sxrjxfjjc`。

词表是**按英文键逐条合并**的，所以版本对不上不会把界面弄坏：

| 你的版本 | 结果 |
|---|---|
| 与 2.2553.1.0 相同 | 完整中文，报告显示「缺键 0 条」 |
| 更新（例如 2.26xx） | 新版新增的词条没翻译，这几处显示英文。报告会显示「缺键 N 条」 |
| 更旧 | 正常。多余的键用不上，不报错也不空白 |

根源是 Claude 查不到中文键就**回落到英文词表**：缺翻译只会显示英文原文，
不会让界面报错或空白，所以放心装。

**第 2 步结尾那份报告是唯一需要看的东西：**

```
菜单栏 / 对话框：中文 784 条 / 英文 705 条，缺键 0 条
网页前端界面：中文 31549 条 / 英文 29442 条，缺键 0 条
```

「缺键 0 条」= 完美。若是「缺键 N 条」，说明你的 Claude 比词表新，有 N 个新词条
还没中文，界面只在这几处残留英文，其余照旧。把这份报告发给作者即可补上。

### 更值得注意的是：上游包本身挑版本

本补充包是纯词表合并，几乎不挑版本。但**第 1 步的上游汉化包不是**——
它要改 Claude 的前端语言白名单等内部文件，这些跟版本强相关。

如果你的 Claude Desktop 明显比上游 1.4.7 适配的版本新，**第 1 步可能直接失败**，
那就卡住了（补充包单独装没有意义，界面语言切不过去）。

**只有这种情况下才需要联网**：去上游项目
[javaht/claude-desktop-zh-cn](https://github.com/javaht/claude-desktop-zh-cn)
看有没有更新版本，有就下它的新版走第 1 步（本包不用换），第 2 步照跑。

## 常见问题

**Q：装完界面还是全英文？**
说明**第 1 步没装成功**。本补充包只负责把词表补全，不负责把界面语言切换成中文——
那是上游汉化包干的活（它要改前端语言白名单和 Claude 的语言设置）。
回到第 1 步重跑，注意在它的窗口里选「模式 1」。

**Q：大部分是中文，但还有零星英文？**
先看第 2 步结尾覆盖率报告里的「缺键」数——含义见上方「版本与兼容性」。
另外确认第 3 步做的是「从托盘完全退出」，而不是只关窗口。

**Q：找不到 Python？**
装一个，或者装完确认 `python --version` 在命令行里能跑。

**Q：脚本提示写入失败 / 没有权限？**
右键那个 .bat → 「以管理员身份运行」。另外先确认 Claude Desktop 已从托盘完全退出，
否则程序文件被占用也写不进去。

**Q：Claude Desktop 更新后中文没了？**
正常，更新会覆盖程序文件。按 **第 1 步 → 第 2 步** 重跑一遍即可，两分钟的事。
建议更新后顺手重跑一次。

**Q：Cowork / 沙箱功能坏了？**
那是第 1 步选错模式导致的（选了完整模式）。用上游安装程序卸载后重装并选模式 1。

## 卸载

- **只撤销补充包**：双击 `卸载还原.bat`
- **完全卸载**：先跑 `卸载还原.bat`，再运行 `upstream\install-windows.bat`，
  在里面选卸载选项（会从备份还原）

## 已知限制

- 按 Claude Desktop **2.2553.1.0** 制作。版本差异会造成什么、怎么看，见上方
  「版本与兼容性」。
- 只支持 Windows。macOS 用上游包的 `install-mac.command`，但没有这份补充词表。
- 只做界面显示层翻译，不改任何请求内容、模型路由或账号数据。
